# SYNTHETIC fixture — not a real T-8 backup

These files were generated by a script to match the `.prm` text format that the
open-source AIRA Pattern Editor (natebosch/aira_pattern_editor) reads and writes.
They are **not** copied from a physical Roland T-8 and the file names
(`PTN01.PRM` …) are placeholders: the real backup file names are unknown.

They exercise the parser/serializer (round-trip, single-step edits, unknown
fields like `CY`, `SCALE`, `FLAM`, `TRIPLET`, CRLF line endings in slot 2).

To test against your own hardware, copy a real backup (the folder containing
`BASS` and `RHYTHM`) to `Tests/T8CoreTests/Fixtures/real-backup/BACKUP/`.
The `RealBackupTests` then run automatically; they are skipped when absent.
