# Roland T-8

Everything here comes from Roland's **T-8 MIDI Implementation Chart v1.02** and the owner's manual. Nothing about the device's internal formats is assumed.

## Facts used

| | Value |
|---|---|
| Rhythm channel (default) | 10 |
| Bass channel (default) | 2 |
| Program change channel | 16; programs 0–63 select patterns |
| Rhythm notes (transmitted / also received) | BD 36 (35), SD 38 (40), HC 50 (48), TOM 47 (45), CH 42 (44), OH 46 |
| Bass note range | 12–96 |
| Received realtime | Clock, Start, Stop, Continue |
| Not received | Control change, pitch bend, SysEx |
| Pattern memory | 64 patterns, up to 32 steps each |
| Slide | Played legato: the next note starts before the previous one ends |

## Conversion

`engine/kstem/export/t8.py` turns the drum and bass stems' notes into patterns:

- The grid starts at bar 1 (the project's downbeat); each step is a sixteenth note at the project tempo. Parts longer than one pattern are cut into consecutive 16- or 32-step patterns.
- Each drum hit goes to its nearest step. Drum classes map to the six T-8 voices with the editable drum map (defaults: rim → SD, crash → OH, ride → CH, toms → TOM, other percussion → not mapped). Two hits on one voice and step merge into one; hits louder than the pattern's typical velocity become accents.
- The bass is made monophonic; notes outside 12–96 are transposed by octaves into range; long notes become tied steps; a note that overlaps the next one becomes a slide.
- The report lists every change: hits merged, unmapped, before bar 1 or after the last pattern, notes transposed, overlaps resolved.

## Modes

- **Mode A: MIDI pattern file.** Rhythm on channel 10, bass on channel 2, patterns back to back. Play it into the T-8 from a DAW or sequencer.
- **Mode B: play into the T-8.** The app sends the notes over USB MIDI (CoreMIDI), optionally with MIDI clock and Start/Stop so the T-8's tempo follows. This is playback. Roland does not document recording incoming MIDI into a pattern, so the app never says a pattern was saved.
- **Mode C: native pattern files.** Not offered. The backup/`.prm` format is not published; T-8 Pattern Studio's work on it is waiting on real, unmodified backups. Writing unverified files to the device could damage its memory.

## Hardware check (needs a T-8)

1. Connect the T-8 by USB; Export > Roland T-8 should list it as an output (marked "(T-8)").
2. Convert a drum stem and a bass stem, then **Play into T-8** with clock on.
   Expected: kick, snare, hats on the right voices; bass notes at the right pitch; slides glide.
3. Turn clock off and play again: notes still sound (the T-8 plays incoming notes without running).
4. Save the Mode A file, play it from Live into the T-8: same result.
5. Optional, unknown outcome: put the T-8 in pattern write/record mode while playing and note whether anything is recorded. Tell us what happened so T8.md can be updated.
