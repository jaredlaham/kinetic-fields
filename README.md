# Kinetic Fields Live

A browser-based realtime audio-reactive visualizer built for live performance, projection, DJ sets, immersive installations, and fullscreen VJ playback.

Kinetic Fields Live transforms microphone or system audio into cinematic WebGL-inspired visuals directly in the browser — optimized for Framer embeds, fullscreen playback, and performance-first rendering.

Designed and developed by Kinetic Fields  
https://kineticfields.xyz

---

## Features

- Realtime audio-reactive visuals
- Browser-based (no install required)
- Optimized for live performance + fullscreen projection
- Framer-compatible
- GPU-inspired shader aesthetics using performant Canvas rendering
- Texture/palette engine shared across all modes
- Keyboard-controlled VJ workflow
- Auto VJ mode
- Responsive + mobile-friendly
- Lightweight enough for embedded live websites

# Visual Modes

## Fluid
Organic flowing liquid simulation with audio-reactive movement.

## Liquid Metal
Smooth chrome/metaball-inspired liquid renderer with:
- viscous blob motion
- reflective ribbon highlights
- animated film grain
- texture-aware palettes

## Lightning
Chaotic branching lightning system with:
- randomized strike positions
- branching arcs
- chromatic glow
- audio-reactive intensity

## ASCII
Performance-optimized shader-style ASCII renderer with:
- realtime character animation
- audio-reactive movement
- scalable typography sizes
- texture-aware colorization

## Pulse
Audio-reactive cube visualization inspired by shader heatmaps.

## Ripple
Minimal reactive wave propagation mode.

## Orb
Glowing energy orb / particle field mode.

## Retrowave
Retro-futuristic neon waveform environment.

## Star
Deep-space starfield visualization.

# Controls

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `← / →` | Cycle visualization modes |
| `H` | Toggle Auto VJ |
| `K` | Toggle UI visibility |
| `J` | Toggle Kinetic Fields logo |
| `L` | Toggle logo black/white |
| `G` | Toggle grayscale mode |
